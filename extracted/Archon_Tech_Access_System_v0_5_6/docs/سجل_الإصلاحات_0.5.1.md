# سجل الإصلاحات — Archon Tech Access System 0.5.1

**النسخة الأم:** 0.5.0 الأصلية، محفوظة كما هي في حزمة الإصدار السابق. جميع هذه التغييرات أُجريت في نسخة عمل منفصلة.

| المعرف | الملف/المجال | ما تم | الحالة بعد الإصلاح |
|---|---|---|---|
| A-01 | `Install_Archon_Tech.ps1` | UTF-8 BOM وCRLF، مراجعة النصوص العربية والمسارات وفحص الملفات؛ أضيف اختبار Parser على Windows | إصلاح المصدر؛ اختبار Parser الفعلي مطلوب على Windows |
| A-02 | `Backup_Restore_Archon.ps1` | UTF-8 BOM واحد وCRLF؛ أزيلت علامة BOM ثانية متكررة اكتُشفت في المراجعة النهائية | إصلاح المصدر؛ اختبار Parser الفعلي مطلوب على Windows |
| A-03 | النسخ والاستعادة | staging، manifest SHA-256، التحقق من قواعد Access، نسخة أمان، نقل مرحلي وrollback flags، وحفظ مجلد الفشل | معالجة برمجية؛ يلزم اختبار حقن فشل فعلي على Windows |
| A-04 | صلاحيات ACCDB | لا يمكن فرض حماية خادمية من داخل VBA على ملف BE متاح للمستخدم | غير محلول معماريًا؛ يلزم NTFS أو Backend خادمي |
| A-05 | سجل التدقيق | fallback نصي عند فشل DAO، إظهار فشل التسجيل إذا فشل fallback، وإدراجه ضمن النسخ | تحسين جزئي؛ ليس ذريًا ولا مقاومًا للتعديل |
| A-06 | فحص المثبت | فحص Access.Application وVersion 16.x وDAO Workspace والوصول إلى ActiveVBProject قبل الاستيراد | تحسين جزئي؛ لا يميز build 2016/2019/2021/2024 ولا يُختبر COM هنا |
| A-07 | مجلد التثبيت | اشتراط مجلد مستقل فارغ وفحص صلاحية الكتابة | إصلاح ساكن |
| A-08 | إعادة ربط BE | preflight لكل جدول، حفظ Connect السابق، rollback عكسي وإظهار أخطاء rollback | إصلاح ساكن؛ يلزم Access runtime |
| A-09 | المرفقات | SHA-256 محسوبة فعليًا، أزرار إرفاق للإيصالات والمدفوعات العامة والمدفوعات المرتبطة بالمصروفات، وسجل جانبي محفوظ في Backup | جزئي؛ إضافة/ربط/هاش متاحة في المصدر، واجهة فتح/استعراض لم تكتمل |
| A-10 | الإقفال المالي | فحص الأيام المغلقة على DateValue، ورصيد حتى `< اليوم التالي` بدل حد 23:59:59 | إصلاح ساكن؛ يلزم اختبار حدود التواريخ في Access |
| A-11 | استعلامات التقارير | إنشاء الاستعلامات مرة واحدة في `AT_BuildInitialUI` وقبل النماذج، وإزالة التكرار من المثبت | إصلاح ساكن |
| A-12 | اختبار 0.3.1 | نقله إلى `reference/tests_0_3_1` وضبط مصدره التاريخي | إصلاح؛ نتائج منفصلة عن الإصدار الحالي |
| A-13 | اختبارات PowerShell | فحص علامة BOM واحدة فقط لكل ملف PS1 ضمن 42 اختبارًا وإضافة Parser script يفحص جميع ملفات PS1 عبر PowerShell AST | أضيفت الاختبارات؛ Parser script لم يُنفذ هنا |
| A-14 | أقفال Access | `Get-ChildItem -Force` مع فحص `.laccdb` و`.ldb` | معالجة ساكنة؛ اختبار hidden/system الحقيقي ما يزال مطلوبًا |
