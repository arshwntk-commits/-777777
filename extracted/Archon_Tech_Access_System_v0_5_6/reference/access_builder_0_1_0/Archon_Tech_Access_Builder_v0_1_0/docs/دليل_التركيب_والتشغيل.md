# دليل تركيب حزمة Archon Tech داخل Access 2021 / 2024

## 1. تجهيز ملف القاعدة

1. افتح Microsoft Access.
2. اختر **Blank database / قاعدة بيانات فارغة**.
3. سمّ الملف `Archon_Tech_Sewer_Contributions.accdb`.
4. احفظه في مجلد عمل ثابت، مثل `C:\ArchonTech\SewerProject\`.
5. لا تستخدم ملف ACCDE في مرحلة البناء. نحتاج ملف ACCDB قابلًا للتحرير.
6. احتفظ بنسخة فارغة أصلية قبل تشغيل أداة البناء.

## 2. استخراج حزمة البناء

1. استخرج ملف ZIP إلى مجلد مستقل، مثل `C:\ArchonTech\Builder\`.
2. افتح ملف القاعدة الذي أنشأته.
3. اضغط `Alt + F11` لفتح محرر Visual Basic for Applications.
4. من محرر VBA اختر **File > Import File**.
5. استورد ملفات `VBA` بالترتيب الوارد في README_AR.md.
6. بعد استيراد الملفات كلها اختر **Debug > Compile**.
7. احفظ المشروع من محرر VBA، ثم ارجع إلى Access.

لا تحتاج هذه الحزمة إلى تفعيل خيار **Trust access to the VBA project object model**؛ فهي لا تحاول تعديل مشروع VBA بنفسها. إذا منع Access تشغيل الأكواد، استخدم مجلدًا موثوقًا من Trust Center أو وافق على محتوى الملف وفق سياسة الأمان لديك. لا تغيّر إعدادات الأمان العامة إلى Enable All Macros لكل الملفات.

## 3. تشغيل البناء الآلي

1. من Access اضغط `Ctrl + G` لفتح نافذة Immediate في محرر VBA.
2. اكتب الأمر التالي ثم اضغط Enter:

```vb
BuildArchonSystem
```

3. وافق على رسالة بدء البناء.
4. ينتج الإجراء الجداول والعلاقات والاستعلامات والنماذج والتقارير الأساسية.
5. افتح النموذج `frmAT_Home` أو أعد فتح القاعدة؛ ستُضبط شاشة البداية على لوحة Archon Tech.
6. افتح الجدول `tblAT_BuildLog` لمراجعة خطوات البناء والفحوص.

**إعادة التشغيل:** الإجراء مصمم لتجنب حذف الجداول والبيانات والكائنات الموجودة. لكنه لا ينفذ ترحيلًا شاملًا لتغيير أنواع حقول موجودة أو إصلاح تصميم قديم تلقائيًا. أفضل نتيجة أولى تكون على قاعدة فارغة جديدة.

## 4. إعداد أول بيانات تجريبية

1. من لوحة التحكم افتح **إدارة الملاك** واضغط **مالك جديد**.
2. أدخل الاسم ورقم الهاتف والعنوان، ثم اضغط حفظ السجل.
3. افتح **الوحدات والشقق** واضغط **وحدة جديدة**. اختر المالك، وأدخل المبنى والشقة والطابق.
4. القيمة الافتراضية للمساهمة 3000 ريال يمني لكل وحدة، ويمكن تعديلها في سجل الوحدة قبل إنشاء الاستحقاقات.
5. افتح **الاستحقاقات** واضغط **إنشاء استحقاقات الوحدات**. ينشئ النظام استحقاقًا أوليًا واحدًا لكل وحدة نشطة لم يُنشأ لها استحقاق INITIAL من قبل.
6. الحساب النقدي الافتراضي وطُرق الدفع الأساسية تُضاف تلقائيًا عند أول بناء. أضف الحسابات البنكية والمحافظ من شاشة الحسابات المالية.

استخدم بيانات وهمية في الاختبارات الأولى. لا تستخدم أسماء أو أرقامًا أو معاملات حقيقية حتى إكمال الاختبارات والمراجعة.

## 5. تجربة إيصال تحصيل

1. افتح إيصالات التحصيل واضغط إيصال جديد.
2. اختر المالك وطريقة الدفع والحساب، وأدخل التاريخ والمبلغ واسم الدافع والمحصل.
3. اضغط حفظ المسودة.
4. راجع البيانات، ثم اضغط اعتماد الإيصال.
5. بعد الاعتماد يُنشأ رقم الإيصال، وتُسجل حركة موجبة في الحساب، ويوزع المبلغ على أقدم الاستحقاقات أولًا.
6. أي زيادة على المستحقات تُسجل في سجل رصيد المالك الدائن ولا تضاف إلى المتحصلات مرة ثانية.

لا تضغط اعتماد قبل حفظ المسودة. الحركات غير المعتمدة لا تدخل في رصيد الحساب.

## 6. المصروفات وسندات الصرف

1. سجّل المصروف في شاشة المصروفات، وحدد المستفيد والتصنيف والبيان والمبلغ.
2. احفظ المصروف.
3. أنشئ سند صرف، وحدد النوع `EXPENSE`، واربط المصروف، وأدخل المستفيد والمبلغ وطريقة الدفع والحساب.
4. يجب أن يطابق مبلغ السند مبلغ المصروف المرتبط.
5. احفظ المسودة ثم اعتمد السند. سيمنع النظام الاعتماد إذا لم يكفِ الرصيد المتاح.

يمكن أن يكون المستفيد شخصًا أو جهة ليست مالكًا.

## 7. التحويلات الداخلية

1. أنشئ تحويلًا جديدًا وحدد حساب المصدر والوجهة والمبلغ والرسوم.
2. احفظ المسودة واضغط **بدء وحجز التحويل**. تُحجز قيمة التحويل والرسوم من الرصيد المتاح.
3. بعد تنفيذ التحويل فعليًا وتحقق وصوله، اضغط **تأكيد وصول التحويل**.
4. لا يُضاف المبلغ إلى الحساب الوجهة قبل التأكيد. التحويل ليس إيرادًا أو مصروفًا؛ رسوم التحويل فقط تخفض حساب المصدر كحركة منفصلة.

## 8. الخصومات والعكس

- طلب الخصم يبقى Pending ولا يغير الاستحقاق قبل الموافقة.
- الاعتماد يحفظ قيمة الاستحقاق قبل وبعد التعديل، ويرفض التخفيض إذا جعل المبلغ أقل من المبالغ الموزعة عليه.
- عكس الإيصال يضيف حركات عكسية ولا يحذف الأصل. لا يعني العكس المحاسبي رد النقد فعليًا.
- رد الرصيد الدائن الفعلي عملية دفع مستقلة من نوع `OWNER_REFUND`، وتحتاج رصيدًا دائنًا كافيًا ورصيد حساب كافيًا.

## 9. الاختبارات البنيوية

من لوحة التحكم اضغط **فحص النظام**، أو من Immediate نفّذ:

```vb
RunArchonStructuralTests
```

هذا الفحص يتحقق من وجود الجداول والاستعلامات والنماذج والتقارير. **لا يثبت وحده صحة الحسابات المالية أو الطباعة أو سلوك النماذج.** راجع `tests/خطة_الاختبار_العملي.md` ونفّذ الحالات يدويًا في Access.

## 10. إذا ظهر خطأ

أرسل هذه المعلومات:

- إصدار Access (2021 أو 2024) و32-bit أو 64-bit إن أمكن.
- رسالة الخطأ كاملة ورقمها.
- اسم الإجراء أو الوحدة والسطر المظلل في محرر VBA.
- آخر صفوف `tblAT_BuildLog` إن كان الجدول قد أُنشئ.

لا تحذف الجداول ولا تحاول إعادة بناء القاعدة فوق بيانات مهمة قبل حفظ نسخة احتياطية.
