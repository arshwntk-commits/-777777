# حالة التنفيذ والحدود المعروفة — الإصدار 0.1.0

## ما تم تضمينه في الحزمة

- وحدات VBA لإنشاء البنية الأساسية والجداول والعلاقات والفهارس والاستعلامات.
- نماذج إدخال أولية تُنشأ برمجيًا، تشمل الملاك والوحدات والاستحقاقات والإيصالات والمصروفات وسندات الصرف والتحويلات والحسابات وطلبات الخصم وطرق الدفع والتصنيفات.
- لوحة تحكم وأزرار لفتح النماذج والتقارير، وحفظ المسودات واعتماد العمليات الأساسية.
- دفاتر حركة للحسابات والرصيد الدائن للمالك.
- وظائف أساسية لاعتماد الإيصال وسند الصرف والتحويل والخصم وعكس الإيصال.
- تقارير أولية للمتأخرات وأرصدة الحسابات والإيصالات والمصروفات.
- سجل البناء وفحص بنيوي.

## ما لم يكتمل بعد، ولا يجوز اعتباره منجزًا

1. **إقفال الفترات:** الجداول موجودة، لكن إجراءات الإنشاء والاعتماد وإعادة الفتح والمطابقة مع الرصيد الفعلي لم تكتمل.
2. **النسخ الاحتياطي والاستعادة:** لم تنشأ واجهة آمنة داخل التطبيق بعد. استخدم نسخة احتياطية عبر Access بعد إغلاق القاعدة/وفق آلية النسخ الاحتياطي المدعومة، ولا تنسخ ملفًا مفتوحًا يدويًا باعتبار ذلك نسخة مضمونة.
3. **صلاحيات المستخدمين وتسجيل الدخول:** الجدول الأولي موجود، لكن المصادقة والصلاحيات الفعلية غير منفذة. Access ACCDB وحده لا يوفر نظام أمان قويًا للتطبيق متعدد المستخدمين.
4. **حماية كلمات المرور:** لا توجد شاشة كلمة مرور أو تخزين لكلمة المرور في هذه الدفعة؛ لذلك لم تُخزّن القيمة الافتراضية `12345` كنص مكشوف. إذا أضيف تسجيل الدخول لاحقًا فيجب فرض تغييرها فورًا وعدم اعتبارها حماية قوية.
5. **إلغاء التحويل المعلق:** الحجز يعمل، لكن زر إلغاء الحجز وإطلاق الرصيد لم يضاف بعد.
6. **عكس سند الصرف:** عكس الإيصالات موجود، لكن عملية عكس سند صرف معتمد وإعادة المبلغ أو التسوية المقابلة تحتاج مرحلة منفصلة.
7. **توزيع الإيصال يدويًا:** التوزيع التلقائي على أقدم الاستحقاقات موجود؛ واجهة تعديل التوزيع قبل الاعتماد لم تكتمل.
8. **طباعة إيصال فردي:** سجل الإيصالات قابل للتقرير، لكن قالب إيصال رسمي فردي بتصميم نهائي وتفقيط المبلغ كتابةً والتوقيعات يحتاج اعتماد نموذج الطباعة المرجعي.
9. **المرفقات:** الجدول يحفظ مسار الملف فقط؛ إدارة النسخ الفعلية للمرفقات ضمن النسخ الاحتياطي لم تكتمل.
10. **سجل التدقيق الشامل:** العمليات المالية الأساسية تسجل، لكن كل تعديل يدوي لبيانات المالك والوحدة والإعدادات والصلاحيات لا يُسجل بعد تلقائيًا.
11. **مراجعة تكامل البيانات والبحث الشامل:** تم تضمين تطبيع عربي أولي للبحث عن المالك بالاسم/الرقم/الهاتف؛ البحث الشامل في كل المستندات والتواريخ والمبالغ لم يكتمل.
12. **التحقق التشغيلي:** لم تُنفذ هذه الحزمة داخل Access في بيئة إعدادها؛ الفحص الساكن لا يثبت نجاح CreateForm أو CreateReport أو حسابات DAO في جهازك.

## توصية الاستخدام

هذه نسخة تطوير وتجربة فقط. ابدأ بقاعدة ACCDB فارغة وبيانات تجريبية. لا تسجل أموالًا حقيقية ولا توزع النظام للمستخدمين قبل معالجة البنود أعلاه، ومراجعة تصميم الإيصال، وتنفيذ اختبار القبول الكامل على Access 2021/2024.
