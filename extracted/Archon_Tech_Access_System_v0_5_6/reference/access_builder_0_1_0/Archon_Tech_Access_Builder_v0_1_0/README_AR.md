# Archon Tech — حزمة بناء نظام تحصيل رسوم المجاري

**الإصدار:** 0.1.0 — حزمة البناء الأولية الجديدة  
**المنصة المستهدفة:** Microsoft Access 2021 وMicrosoft Access 2024 (نسخة ACCDB)  
**لغة الواجهات:** العربية، مع أسماء كائنات وحقول داخلية باللغة الإنجليزية لتسهيل صيانة VBA.

> هذه حزمة مصدر وبناء أولية، وليست ملف قاعدة بيانات جاهزًا. لا تحتوي على ملف `.accdb` لأن ملف القاعدة الأصلي سينشئه المستخدم داخل Access. كما لم تُشغّل هذه الأكواد على Microsoft Access في بيئة إعداد الحزمة؛ يجب تنفيذ خطوات التركيب والاختبار على جهاز Windows الذي يحتوي على Access.

## ماذا تنشئ الحزمة؟

- 22 جدولًا للبنية الأساسية: الإعدادات والمستخدمون والملاك والوحدات والاستحقاقات والإيصالات والتوزيعات والأرصدة الدائنة وطرق الدفع والحسابات والمصروفات وسندات الصرف والتحويلات والحركات المالية والخصومات والتدقيق والإقفالات والمرفقات وسجل البناء.
- فهارس أساسية وعلاقات بين الكيانات الرئيسية.
- استعلامات لأرصدة الملاك والمتأخرات والحسابات المتاحة وسجل الإيصالات والمصروفات والتحويلات وطلبات الخصم وكشف المالك.
- نماذج إدخال عربية أولية تُنشأ برمجيًا، مع أزرار للعمليات الأساسية.
- قوالب تقارير قابلة للمعاينة.
- وظائف مالية أساسية لاعتماد الإيصالات وسندات الصرف، وتوزيع الدفعات على أقدم الاستحقاقات، وتسجيل الزيادة كرصيد دائن، واستخدام الرصيد الدائن، وحجز التحويل المعلق وإتمامه، واعتماد الخصم، والعكس المحاسبي للإيصال.
- سجل بناء وفحص بنيوي.

## ترتيب الاستيراد

استورد ملفات `.bas` إلى محرر VBA بهذا الترتيب:

1. `modAT_Core.bas`
2. `modAT_Schema.bas`
3. `modAT_Queries.bas`
4. `modAT_Finance.bas`
5. `modAT_Reports.bas`
6. `modAT_Forms.bas`
7. `modAT_Tests.bas`
8. `modAT_Build.bas`

بعد الاستيراد، نفّذ **Debug > Compile** قبل البناء. إذا ظهرت أخطاء ترجمة، لا تشغّل إجراء البناء؛ أرسل صورة السطر ورسالة الخطأ.

## تحذير بخصوص النسخة

هذه الدفعة هي **الأساس البنيوي والتشغيلي الأول** وليست الإصدار النهائي 1.0. توجد وظائف مخطط لها لم تُنفّذ بعد في هذه الدفعة، وتفاصيلها في `docs/الحالة_والحدود.md`. لا تستخدمها لإدارة أموال حقيقية قبل إكمال الوظائف الناقصة والاختبارات العملية.
