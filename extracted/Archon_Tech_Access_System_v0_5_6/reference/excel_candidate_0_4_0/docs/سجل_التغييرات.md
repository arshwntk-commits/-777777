# سجل التغييرات — v0.4.0 Candidate

- بدأ المرشح من قالب Excel المستقل الفارغ بدل النسخة التي تحتوي بيانات اختبار متعارضة.
- الحفاظ على مشروع VBA الثنائي المضمّن دون تعديل.
- تحديث تعليمات الورقة لتوضيح متطلبات Excel المكتبي لـVBA.
- تفعيل إعادة الحساب التلقائي عند فتح المصنف.
- إضافة نسخة احتياطية مستقلة من `vbaProject.bin` إلى ZIP.
- إضافة مصدر مقروء من `Module_Collection.bas` التاريخي وموديول مركز رسائل مقترح، غير مدمج.
- تضمين مراجع Access 0.3.1 كاملة، ومصفوفة متطلبات نقل إلى Excel، وقواعد الحسابات والصلاحيات والرسائل.
- التحقق من بنية ZIP، وجود VBA، الأوراق، الجداول، وصيغ نموذج الإيصال.

## حدود التغيير
لم يتم تعديل VBA الثنائي أو تجميعه، ولم يتم تنفيذ اختبارات داخل Microsoft Excel. لا يعد هذا إصدار إنتاجي 1.0.
