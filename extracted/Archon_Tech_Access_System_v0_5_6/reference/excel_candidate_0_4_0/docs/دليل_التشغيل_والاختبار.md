# دليل التشغيل الآمن وحدود النسخة المرشحة

## أين يعمل؟
هذا المصنف يحتوي VBA، ولذلك يلزم Excel المكتبي على Windows لتشغيل الماكرو. Excel على Android لا يشغل VBA، وExcel للويب لا ينشئ أو يشغل أو يحرر VBA. يمكن أن تحتفظ التطبيقات المحمولة بالملف وتعرض بياناته، لكنها ليست بيئة تشغيل هذه الوظائف.

## أول فتح
1. انسخ الملف إلى مجلد محلي موثوق.
2. احتفظ بالنسخة الأصلية كما هي، وافتح نسخة الاختبار فقط.
3. تحقق من أن اسم المصنف ينتهي بـ `.xlsm`.
4. لا تفعّل الماكرو إلا بعد فحص الملف ومصدره.
5. راجع الإعدادات، واسم الحارة، ومعدل المساهمة، واسم المسؤول والمحصّل.
6. لاحظ أن القالب يذكر سعة 200 مالك و500 حركة؛ لا تتجاوزها قبل التوسعة والاختبار.

## حدود النسخة
هذه النسخة مرشح متابعة مبني على مصنف تاريخي موجود؛ ليست نسخة 1.0 إنتاجية. لا يوجد فيها بعد واجهات صرف وتحويل وإقفال ونسخ/استعادة ومستخدمين كاملة. لا تستخدمها لتسجيل أموال حقيقية أو لإثبات أرصدة رسمية.

## حماية البيانات
- حماية الورقة تمنع التعديل غير المقصود فقط؛ ليست حماية أمنية.
- لا تشارك ملف XLSM مفتوحًا للكتابة المتزامنة من عدة أجهزة عبر OneDrive.
- خذ نسخة مؤرخة قبل كل اختبار مالي.
- لا تحذف أو تعدّل صفًا معتمدًا يدويًا.
- لا تُصلح أي فرق مالي بإضافة رقم غير موثق.

## خطوات ما قبل الإصدار النهائي
1. فتح نسخة اختبار في Excel Windows.
2. فتح محرر VBA وتشغيل Debug > Compile.
3. إضافة الوحدات الجديدة بعد مراجعتها وربط جميع الأزرار والأحداث بالخدمات المركزية.
4. تنفيذ اختبار إدخال مالك، واستحقاق، وقبض، وتخصيص، ودائن، وعكس، وصرف، وتحويل، وإقفال، ونسخ/استعادة.
5. إعادة فتح المصنف بعد الإغلاق وإعادة حساب الأرصدة ومقارنتها.
6. اختبار الطباعة، إعادة طباعة إيصال تاريخي، PDF، العربية واتجاه RTL.
7. إصدار النسخة النهائية فقط بعد نجاح الاختبارات وحفظ سجل النتائج.
