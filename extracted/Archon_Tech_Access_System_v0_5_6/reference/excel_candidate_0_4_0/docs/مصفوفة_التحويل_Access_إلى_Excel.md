# مصفوفة تحويل متطلبات Access إلى Excel

| المجال/الكيان | تمثيله الحالي في Excel | المطلوب للوصول إلى النظام المتكامل |
|---|---|---|
| إعدادات المشروع ومعدل المساهمة | ورقة الإعدادات؛ معدل افتراضي 3,000 ريال | تاريخ نفاذ المعدلات وعدم تغيير الاستحقاقات التاريخية وتدقيق كل تعديل |
| الملاك | جدول OwnersTable، نموذج بيانات محدود | حالات مستقلة، بحث عربي مرن، أرشفة، مراجعة تكرار، سجل قيم قديمة/جديدة |
| الاستحقاقات | مبلغ مستحق بصيغة إجمالي الشقق × السعر الحالي | سجل استحقاقات متعدد الفترات مع لقطة سعر/شقق ودفعات إنشاء تمنع التكرار |
| الإيصالات | جدول CollectionsTable ونموذج تسجيل/إيصال | مستند موحد، مسودة/اعتماد، تخصيص متعدد الأسطر، توزيع تلقائي للأقدم مع معاينة وتأكيد واعتماد مرة واحدة |
| التخصيصات والتسويات | أثر مالي إجمالي داخل أعمدة سجل التحصيل | دفتر تسويات تفصيلي يربط كل إيصال بكل استحقاق، وعكس جزئي موثق |
| الرصيد الدائن | عمود الزيادة في سجل الملاك/الحركة | دفتر مستقل للحركات الدائنة، تطبيق محدد المصدر، رد نقدي بسند صرف مرتبط |
| الخصومات والإعفاءات | ليست تدفقًا متكاملًا في القالب | طلب، مراجعة، موافقة، لقطة قبل/بعد، لا أثر قبل الاعتماد |
| الحسابات المالية | لا يوجد دفتر حسابات مستقل | صناديق/بنوك/محافظ مع رصيد دفتري من الحركات فقط ورصيد متاح بعد الحجوزات |
| المصروفات/سندات الصرف | غير متكاملة | مسودة، مستفيد، فئة، حساب، تأكيد دفع، منع تجاوز المتاح، عكس موثق |
| التحويلات | غير متكاملة | حساب مصدر/وجهة، رسوم مستقلة، حجز المصدر، أموال بالطريق، تأكيد الوصول |
| المستخدمون والصلاحيات | اسم المستخدم/حماية ورقة موروثة فقط | Users/Roles/Permissions، أقل صلاحية افتراضيًا، فحص إذن في كل إجراء حساس، مع الاعتراف بحدود Excel |
| الأرقام الرسمية | OW/RC في الكود القديم | سلاسل مستقلة لكل نوع، التخصيص لحظة الاعتماد، تفرد وعدم إعادة استخدام |
| سجل التدقيق | جدول AuditTable مبسط | أحداث وتغييرات قبل/بعد، سبب ونتيجة وهوية وتوقيت لكل عملية حساسة |
| التقارير | لوحة وتقارير مختصرة | كشف مالك، متأخرات، إيصالات، صرف، حركة حساب، دائن، تحويلات، إقفال، تدقيق وسلامة |
| الطباعة وPDF | نموذج إيصال أولي/معاينة | قوالب رسمية مستقلة عن ألوان الواجهة، مبلغ بالحروف، إعادة طباعة تاريخية دون حركة جديدة، تصدير PDF مختبر |
| الإقفال | ورقة تقارير/إقفال أساسية فقط | لقطة لكل حساب، دفتر/فعلي/فرق، منع إغلاق مع فروق غير محلولة، إعادة فتح بصلاحية وسبب |
| النسخ والاستعادة | تعليمات نسخ يدوية فقط | نسخ بمسار يختاره المستخدم، تحقق من الاكتمال، نسخة قبل الاستعادة، سجل نتائج |
| المرفقات | لا يوجد تدفق | فهرس ومسار نسبي وبصمة SHA-256، فحص الوجود ونسخ المجلد |
| فحص السلامة | فحوص بسيطة في أعمدة الحركة | قواعد تناقض مفصلة، درجات خطورة وحالة معالجة، دون إصلاح آلي |
| رسائل النظام | MsgBox متفرقة في VBA التاريخي | مركز رسائل موحد: خطأ/تحذير/نجاح/تأكيد، ملخص قبل الإجراء، افتراضي تراجع، سبب إلزامي للعمليات الحساسة |

## الجداول المرجعية في مصدر Access 0.3.1
المصدر يحتوي تعريفات 38 جدولًا: `tblProjectSettings`, `tblContributionRates`, `tblUsers`, `tblRoles`, `tblPermissions`, `tblUserRoleAssignments`, `tblRolePermissions`, `tblOwners`, `tblChargeBatches`, `tblFinancialDocuments`, `tblOfficialDocumentNumbers`, `tblNumberSeries`, `tblOwnerCharges`, `tblReceipts`, `tblReceiptAllocationLines`, `tblOwnerAdjustments`, `tblChargeSettlementLines`, `tblReceiptCorrections`, `tblReceiptCorrectionLines`, `tblOwnerCreditMovements`, `tblCreditApplications`, `tblCreditApplicationLines`, `tblAccounts`, `tblPaymentMethods`, `tblExpenseCategories`, `tblPayments`, `tblAccountTransfers`, `tblAccountMovements`, `tblAccountReservations`, `tblFinancialClosings`, `tblFinancialClosingAccounts`, `tblAuditEvents`, `tblAuditChanges`, `tblAttachments`, `tblBackupLog`, `tblIntegrityRuns`, `tblIntegrityFindings`, `tblSchemaVersion`.

هذه القائمة مرجع تصميم/مصدر، وليست قائمة جداول موجودة حاليًا داخل مصنف Excel المرشح.
