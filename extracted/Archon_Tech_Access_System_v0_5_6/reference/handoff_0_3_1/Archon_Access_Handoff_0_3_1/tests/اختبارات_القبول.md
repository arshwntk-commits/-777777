# اختبارات القبول اليدوية داخل Microsoft Access

**استخدم بيانات وهمية فقط.** سجل نتيجة كل اختبار وتاريخها ونسخة قاعدة البيانات. لا تستخدم النظام في التحصيل الفعلي حتى تنجح جميع الاختبارات الحرجة.

| T22 | انقطاع/خطأ أثناء اعتماد حركة | لا تبقى نصف معاملة؛ تُراجع سلامة المعاملة وسجل التدقيق |
| T23 | استهلاك رصيد دائن جزئيًا مرتين | لا يمكن تطبيق أكثر من المتاح من كل حركة دائن |

| T26 | رد رصيد دائن بسند صرف | يتطلب رقم حركة دائن أصلية معتمدة، رصيدًا متاحًا كافيًا، تأكيد الدفع، وسند صرف مرتبطًا بالمصدر |
| T27 | تطبيق رصيد دائن | لا يسمح بتطبيقه على مالك أو استحقاق يخص مالكًا آخر، ولا بتجاوز الرصيد أو المتبقي |
| T28 | كشف أرصدة الملاك | يتطابق إجمالي الاستحقاقات والخصومات والتسويات والرصيد الدائن مع الحركات المعتمدة فقط |
| T29 | أرصدة الحسابات | الرصيد المتاح يساوي الرصيد الدفتري مطروحًا منه الحجوزات النشطة |
| T30 | فشل بناء استعلامات التقارير | يتوقف بناء واجهات تعتمد على الاستعلامات، ولا يعلن أن الواجهة اكتملت |

## تحقق إضافي مطلوب قبل الإصدار
- `Debug > Compile` دون أخطاء.
- التحقق من العلاقات والفهارس الفريدة ومنع الأرقام الرسمية المكررة.
- التحقق من معاملات DAO (commit/rollback) على إصدار Access المستهدف.
- اختبار العربية واتجاه RTL والطباعة/PDF على طابعة فعلية أو PDF.
- اختبار النسخ الاحتياطي والاستعادة مع مجلد المرفقات.
- مراجعة الصلاحيات؛ لا تعتبر إخفاء الجداول أو كلمة مرور واجهة Access حماية مطلقة.

## فحص المصدر خارج Access
شغّل `python tests/فحص_ساكن_الحزمة.py`. هذا الاختبار يتحقق من بعض الاتساق النصي والمنطقي، ولا يحل محل اختبار Access. سجل نجاحه على أنه **فحص ساكن فقط** وليس اختبار قبول للنظام.


## حالات مضافة مع المصدر 0.3.1

| المعرف | الاختبار | النتيجة المطلوبة |
|---|---|---|
| T31 | البحث عن مالك باسم عربي مع اختلاف أ/إ/آ أو التشكيل | يعرض كل المطابقات المناسبة دون تعديل الاسم الأصلي أو دمج سجلات |
| T32 | فتح كشف حساب مالك محدد | تظهر استحقاقاته وتسوياته وخصوماته المعتمدة فقط، مع المدين والدائن والمرجع |
| T33 | إنشاء حساب صندوق/بنك/محفظة | يحفظ رمزًا فريدًا ونوعًا صالحًا، ويبدأ رصيده صفرًا دون حركة افتتاحية |
| T34 | تعديل اسم/هاتف/عدد شقق مالك نشط | يلزم سبب التعديل ويُحفظ سجل التدقيق مع القيمة القديمة والجديدة لكل حقل متغير |
| T35 | تجاوز عداد رسمي طول التعبئة، مثل 999999 إلى 1000000 | ينتج `RC-1000000` دون قص أو إعادة استخدام رقم سابق |
| T36 | الاعتماد ثم إعادة الضغط على زر الاعتماد | تُنشأ الحركة مرة واحدة فقط؛ المحاولة الثانية تُرفض |

هذه الحالات تُنفّذ في نسخة اختبار داخل Access بعد نجاح `Debug > Compile`؛ الفحوص الساكنة لا تحل محلها.
