# Archon Tech — حزمة متابعة مشروع تحصيل رسوم المجاري

> **تنبيه تسليم:** هذه حزمة متابعة/مصدر موثّقة وليست النظام النهائي. لا يوجد فيها ملف `.accdb` أو `.accde`. لا تستخدمها للتحصيل الحقيقي. وثيقة `docs/تشخيص_بيئة_البناء_2026-10-28.md` تشرح العائق المحدد، ووثيقة `docs/مصفوفة_المتطلبات_والحالة.md` تسرد حالة كل مجموعة متطلبات.

## محتويات الحزمة
- `src/`: وحدات VBA التي تُنشئ المخطط والخدمات المالية والاستعلامات والنماذج داخل Microsoft Access.
- `tests/`: الاختبارات الساكنة واختبارات القبول المقصودة للتشغيل في Access.
- `docs/`: التقارير والخطة ومصفوفة المتطلبات وتشخيص البيئة.
- `legacy_reference/`: مستندات التصميم والتدقيق، أكواد سابقة، وقوالب Excel القديمة للحفظ التاريخي فقط.
- `RELEASE_NOTES.md`: سجل ما تغير في حزمة المتابعة.

## ما يلزم لاستكمال البناء الصحيح
1. بيئة Windows مثبت عليها Microsoft Access المكتبي ومحرر VBA.
2. إنشاء قاعدة `.accdb` اختبارية فارغة واستيراد وحدات المصدر الأربع.
3. تنفيذ `Debug > Compile` وإصلاح أي أخطاء تظهر قبل تشغيل بناء المخطط.
4. تشغيل `AT_BuildDatabase` ثم `AT_BuildInitialUI` على قاعدة اختبارية فقط.
5. تنفيذ كل حالات القبول وإصلاح الأخطاء وإعادة الاختبارات، ثم بناء تقارير الطباعة/PDF والإقفال والنسخ الاحتياطي وإدارة الصلاحيات الناقصة.
6. بعد نجاح الاختبارات الفعلية فقط، إنشاء إصدار `v1.0` ونسخة احتياطية وحزمة ZIP تتضمن `.accdb` الحقيقي.

## التشغيل اليومي
لا يوجد تشغيل يومي متاح من هذه الحزمة وحدها. لا تفتح ملف VBA أو قوالب Excel على أنها نظام Access نهائي. افتح فقط قاعدة `.accdb` التي تُبنى وتُختبر لاحقًا داخل Access.
